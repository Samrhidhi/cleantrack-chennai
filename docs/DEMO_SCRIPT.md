# 2-minute demo script

Run the app (DartPad or `flutter run -d chrome`). All data shown is simulated.

| Time | Do this | Say this |
|---|---|---|
| 0:00 | Home screen | "CleanTrack connects citizens, sanitation workers and GCC reviewers. Everything you see is simulated data for Chennai." |
| 0:10 | **RUN FULL DEMO** → Continue | "A sensor on Elaya Street in Tondiarpet reports 98% full. The alert goes to dispatch, and the system assigns the e-tricycle, because compactors can't enter that lane." |
| 0:25 | Watch the Live Route | "The route is built from need, not a fixed timetable. It visits only full bins and open complaints, nearest and most urgent first." |
| 0:40 | Demo finishes on the complaint | "The worker can't close this ticket. They file an after-photo with GPS, a reviewer approves it, and the citizen confirms. Every step is in an append-only audit log." |
| 0:55 | Back → **Route Savings** | "A fixed route through all 20 bins is 77 km. The need-based route is 44 km, about 12 litres of diesel saved per trip." |
| 1:10 | **Chronic GVPs** | "Spots dumped on three or more times in 30 days are flagged as chronic, with prevention actions, not just another pickup." |
| 1:25 | Complaints → **CT-2026-1008 (Perungudi)** | "This claim was filed about 550 metres from the site, so the system flagged a GPS mismatch and the reviewer reopened it." |
| 1:40 | **Verify Cleanup** (PIN 9999) | "Each worker has a scorecard: claims, rejections, disputes and GPS flags. That's accountability the city can audit." |
| 1:55 | **Tondiarpet Data** | "We grounded the design in Zone 4 reports: 380 to 420 tonnes a day, under 45% segregation, and a 24-hour SLA we check against open complaints." |
